2. 계정 연결과 인증

Epic·Discord 연결은 사용자가 선택합니다. 게임은 외부 서비스의 로그인 화면을 이용하며 비밀번호를 직접 입력받지 않습니다. 현재 Epic 로그인은 Basic Profile, Discord 로그인은 identify 권한을 요청합니다. 친구 목록과 이메일 접근 권한은 요청하지 않습니다. Discord 접근 토큰은 인증 처리에 사용하며 게임의 저장 파일에 보관하지 않습니다.

3. 저장 위치와 보관

설정과 플레이 기록은 기기에 저장됩니다. 최근 경기 기록은 최대 50개이며, 누적 경기 수·승리 수·최고 점수 등의 요약 기록은 별도로 유지됩니다. EOS 계정이 준비된 경우 기록이 클라우드에 자동 동기화될 수 있습니다. 현재 개발 버전에는 시간 경과에 따른 클라우드 기록 자동 삭제 기능이 없으며, 파일은 덮어쓰기 또는 삭제될 때까지 유지될 수 있습니다. 로컬 파일 삭제만으로 클라우드 데이터가 삭제되지는 않습니다.

현재 게임 코드에는 음성 채팅 녹음·저장 기능이 없습니다. 음성 전송과 네트워크 서비스 운영에 필요한 처리는 서비스 제공자의 정책에 따릅니다.

4. 외부 서비스 및 다른 플레이어

Epic Games의 Epic Online Services는 인증, 계정 연결, 로비·P2P 통신, 음성 채팅, 플레이 기록 저장에 사용됩니다. Discord는 사용자가 선택한 계정의 인증에 사용됩니다. 온라인에서 닉네임, 게임 진행 정보와 사용자가 전송한 음성은 참여한 플레이어에게 전달될 수 있습니다. 외부 서비스의 처리 위치 및 보관 방식은 각 제공자의 정책을 확인해 주세요.

5. 웹사이트와 광고·분석

이 웹사이트는 GitHub Pages로 제공됩니다. 사이트 자체에는 광고, 방문 분석 스크립트, 추적 쿠키를 넣지 않았습니다. GitHub는 호스팅 서비스를 제공하고 보호하기 위해 IP 주소 등 접속 정보를 처리할 수 있습니다. 현재 게임에는 별도의 광고·행동 분석 SDK를 사용하지 않습니다.

6. 정보 확인·삭제와 문의

현재 개발 버전에는 게임 내 계정 삭제 또는 연결 해제 버튼이 없습니다. 정보 확인·정정·삭제 및 계정 연결 관련 요청은 MeMe Games 문의 창구를 통해 접수할 수 있습니다. 공개 문의에는 개인정보나 계정 식별자를 쓰지 말고 비공개 연락 방법을 요청해 주세요. 비밀번호, 인증 코드와 접근 토큰은 보내지 마세요.

외부 계정 자체의 관리나 앱 접근 권한 철회는 Epic Games 또는 Discord의 계정 설정에서도 확인할 수 있습니다. 외부 서비스의 접근 권한 철회와 게임의 저장 데이터 삭제는 서로 다른 절차입니다.

7. 안내 변경

공개 배포 및 기능 변경에 맞춰 이 안내를 갱신하고 수정일을 표시합니다. 현재 공개 배포 전 개발 단계이며, 이 문서는 실제 제공 기능과 함께 확인해 주세요.
